# About

The **Trendix Airdrop Bot** is a Telegram-based system that rewards users in **TRDX tokens** for engaging with Trendix’s **Image-to-Image AI** feature.

**How It Works**

* Users interact with the bot to access the AI, which allows them to upload an image and receive a stylized, AI-generated version.
* Each use of the AI tool is rewarded in **TRDX**, creating a direct incentive to explore Trendix’s technology.
* The bot automatically tracks usage and distributes rewards in real time, ensuring a transparent and frictionless user experience.

**Why It Matters**

* The airdrop bot serves as an **onboarding gateway**, giving new users immediate value while introducing them to Trendix’s AI-powered ecosystem.
* It promotes **community growth**, as users are encouraged to try and share the AI, driving organic exposure and adoption.
* Rewards are distributed **on-chain** and verifiable, reinforcing trust and fairness in the airdrop system.

By rewarding interaction with core features, the Trendix Airdrop Bot builds an active user base around the platform’s AI technology while delivering real value through TRDX tokens.
