# Timełess Token Overview

This section covers the **Timełess token**, the foundational economy token in the Timełess ecosystem.

Unlike TRDX, which focuses on utility and governance, the Timełess token drives large-scale economic activities, staking, yield farming, and cross-chain value flows that underpin the platform’s long-term sustainability.
