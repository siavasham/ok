# AI Systems

## **Text-to-Text AI (Reward Chat)**

This AI functions as a conversational assistant where users can ask questions, generate content, or brainstorm ideas—similar to mainstream language models. However, what sets it apart is its **reward system**.

* **Earn While You Chat:** Users receive **TRDX tokens** for every valid prompt submitted
* **Daily Prompt Limit:** All users get **20 prompts per day**
* **Free Plan:** Earn TRDX only
* **Paid Plans:** Earn both TRDX **and** SOL (Solana)

Each prompt is evaluated based on quality, plan type, and other reward multipliers. This transforms everyday interaction into a token-generating experience while contributing to the improvement of the AI system itself.

{% hint style="warning" %}
Reward Formula: DEP = (Base Points × P × (1 + R) × (1 + T)) × Q × U
{% endhint %}

* **P** = Plan multiplier (Free: 1, Pro: 1.5, etc.)
* **R** = Referral bonus
* **T** = $TRDX token holding bonus
* **Q** = Prompt quality score (0.1 – 1.0)
* **U** = Usage status (1 if under daily limit, 0 if exceeded)

This model rewards both consistency and creativity—encouraging users to generate high-quality prompts and engage frequently.\


## **Image-to-Image AI (Style Generator)**

The Image AI allows users to upload photos and transform them using visual styles such as **Pixar**, **Anime**, or other artistic filters.

* **3 Free Generations per Day (Free Plan)**
* **Each Use = 25 TRDX Reward (for Free Plan)**
* **Paid Plans:** Unlock higher earning limits and exclusive style options
* **Instant Delivery:** Upload → Style → Reward in seconds

Users are incentivized to be creative while sharing stylized images, and each interaction generates value—making the AI not just a tool, but a passive income engine.
